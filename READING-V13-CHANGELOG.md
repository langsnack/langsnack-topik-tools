# Reading Difficulty v13

- Replaced unbounded additive scoring with four bounded, weighted components.
- Moved common intermediate grammar (반면, 기보다는, 뿐만 아니라, 에 따라, 한편) out of the advanced-only group.
- Uses unique evidence normalized by passage length to reduce repeated-word inflation.
- Formal endings cannot independently justify Level 5+.
- Result explanation shows individual component scores.
- Configuration weights now match those actually used by the page.

## Limitations
This is a heuristic beta and has not been validated against official TOPIK-labeled reading corpora. Manual level calibration and vocabulary review are still required. The grammar sentence search is not modified in this release.
