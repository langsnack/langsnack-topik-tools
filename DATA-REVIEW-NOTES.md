# Grammar Finder v10 — review notes

- Grammar Finder now browses entries before typing, filters by estimated level, expands cards with examples, displays related patterns and search variants.
- Corrected several clearly questionable estimates and examples, and added common missing grammar entries with original example sentences.
- All levels remain **unofficial estimates**. Many imported records still require individual pedagogical review.
- Source file references are unverified: no page numbers are claimed.
- Search is fragment-based; it is **not a Korean morphological parser**, so some conjugated surface forms will not match.
- Reading Difficulty is unchanged in this release.
