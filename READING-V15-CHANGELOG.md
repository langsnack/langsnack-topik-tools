# v15 Reading Difficulty beta

- New independent `reading-engine.js`; old v14 heuristic remains in index for historical reference but is not called.
- Inspectable bounded lexical, grammar, structure, and register scores.
- Explicit decision audit: weighted score, evidence floor, thresholds, matched expressions.
- The original four website tools, databases, translations and CNAME are retained.
- This is **not** a trained classifier or an official TOPIK score. The vocabulary database contains unreviewed imported entries.
- Confidence labels reflect limited evidence, not statistically calibrated probabilities.
- Benchmarks are editorial estimates and should not be used as proof of exam-grade accuracy.
