# LANGSNACK TOPIK Tools — Data review notes

This release integrates the supplied 163-entry raw grammar JSON with the latest available website version (v8).

## Review status

- The grammar entries were imported from reference notes and most retain `imported_needs_review`.
- Listed book filenames are **not** verified page citations. The site labels them accordingly.
- TOPIK levels are editorial learning estimates, **not** official exam classifications.
- A small set of obvious import errors was corrected, including the broken `-아/어 주다` pattern, mismatched example for `은/는`, and `-군요` / `-네요` explanations.
- Some elementary patterns had their estimated levels corrected, including `-고 싶다`, `-고 있다`, `-기 때문에`, `-거나`, and `-고 나서`.
- This is not a comprehensive linguistic or textbook-page verification. Check the remaining entries before using the grammar dataset in a commercial reference.

Upload the **contents** of this ZIP to the root of the GitHub Pages repository. Preserve the `CNAME` file.
